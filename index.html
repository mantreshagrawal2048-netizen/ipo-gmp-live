Live IPO GMP Tracker – India

A finance project by · expected IPO listing returns from the grey market premium

How it works
  1. Data collection. Every 30 minutes an automated job (GitHub Actions) opens three public GMP trackers (InvestorGain, IPOGyani and IPOWatch), reads the grey market premium of every open, upcoming and recently closed IPO, and saves it to a data file.
  2. Averaging. The GMP shown is the average of the sources that quote a number for that IPO. Under it you can see each source’s value and whether the sources agree (they “differ” if the highest and lowest quotes are 3% of the issue price or more apart).
  3. Expected return. Expected listing price = issue price (upper band) + GMP. Expected return % = GMP ÷ issue price × 100. Profit per lot = GMP × lot size.
  4. Live page. This page re-reads the data file every 5 minutes and sorts each IPO into open, closed-awaiting-listing or upcoming by its dates.
  5. Accuracy check. After an IPO lists, its final GMP is saved next to the actual listing gain, so the “GMP vs actual” section below shows how reliable GMP really has been.

GMP is an unofficial, unregulated grey-market estimate. It is not an official figure and can be wrong or manipulated. This project is for learning and information only, not investment advice.
