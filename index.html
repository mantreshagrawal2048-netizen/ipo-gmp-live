Live IPO GMP Tracker – India

A finance project by · expected IPO listing returns from the grey market premium

Purpose behind the project

Retail investors invest significant time and effort in locating the Grey Market Premium (GMP) of upcoming IPOs, because neither SEBI nor the stock exchanges publish it. Retail investors in India rely heavily on GMP, often as a primary signal for deciding whether to apply for an IPO and for gauging its expected listing return.

The difficulty is that each source quotes a different GMP, so the same IPO can carry materially different premiums depending on where an investor looks. As a retail investor who experienced this inconsistency first-hand, I built this tracker to provide a single, consistent reference point.

The tracker consolidates GMP from five widely used Indian IPO platforms and publishes their average as one consensus figure, together with the expected listing price and expected return derived from it. The objective is to replace fragmented, conflicting inputs with a transparent, formula-driven estimate that retail investors and traders can verify and use as an informed input to their own decisions.

The tracker also back-tests GMP against actual listing gains, so users can see how reliable the premium has really been. Because GMP is an unofficial indicator, all figures are presented as estimates, not guarantees, and the back-test sample is still small and grows with every new listing.

How it works
  1. Averaging. The GMP shown for each IPO is the average of the sources that quote a number for it (see the Sources tab for the full list and formula).
  2. Expected return. Expected listing price = issue price (upper band) + GMP. Expected return % = GMP ÷ issue price × 100. Profit per lot = GMP × lot size.
  3. Live page. This page re-reads the data file every 5 minutes and sorts each IPO into open, closed-awaiting-listing or upcoming by its dates.
  4. Accuracy check. After an IPO lists, its final GMP is saved next to the actual listing gain, and the section below tests the average, the median and each single source against it, so you can see how reliable GMP has really been and whether averaging helps.
  5. Scope. The expected return is the per-share listing gain implied by GMP. It is not the return on an investor’s capital: brokerage, taxes and allotment odds are not included. Subscription levels, valuation and market conditions also affect listing outcomes and are not modelled here.

Important: GMP is an unofficial, unregulated grey-market estimate. It is not an official figure and can be wrong or manipulated. This project is for learning and information only, not investment advice.

Formula

Average GMP (₹) = (GMP₁ + GMP₂ + … + GMPₙ) ÷ n
n = number of sources counted for that IPO (maximum 5)
Expected return (%) = Average GMP ÷ Issue price (upper band) × 100
Expected listing price (₹) = Issue price + Average GMP

Illustrative example: issue price ₹500; five sources quote ₹40, ₹44, ₹46, ₹50 and ₹45. Average GMP = 225 ÷ 5 = ₹45, so expected return = 45 ÷ 500 × 100 = 9.0% and expected listing price = ₹545.

Only sources that quote a premium for an IPO are counted. A ₹0 shown by IPOWatch or IPO Guru is treated as “no quote” unless another source quotes a premium. If a source’s quotes are found to be identical to another source’s (it is probably copying it), it is left out of the average automatically so the same number is not counted twice. The issue price is also cross-checked across sources. IPOs with no quote anywhere show “No GMP quoted yet”. Use “Show source breakdown” at the top of the page to see each source’s quote, the median and any price differences for every IPO.
