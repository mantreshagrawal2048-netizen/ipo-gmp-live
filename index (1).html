A finance project by · expected IPO listing returns from the grey market premium

Purpose behind the project

Retail investors invest significant time and effort in locating the Grey Market Premium (GMP) of upcoming IPOs, because neither SEBI nor the stock exchanges publish it. Industry research indicates that more than 70% of retail investors in India rely heavily on GMP, often as their primary signal for deciding whether to apply for an IPO and for gauging its expected listing return.

The difficulty is that each source quotes a different GMP, so the same IPO can carry materially different premiums depending on where an investor looks. As a retail investor who experienced this inconsistency first-hand, I built this tracker to provide a single, dependable reference point.

The tracker consolidates GMP from five widely used Indian IPO platforms and publishes their average as one consensus figure, together with the expected listing price and expected return derived from it. The objective is to replace fragmented, conflicting inputs with a transparent, formula-driven estimate that retail investors and traders can verify and use as an informed input to their own decisions.

How it works
  1. Averaging. The GMP shown for each IPO is the average of the sources that quote a number for it (see the Sources tab for the full list and formula).
  2. Expected return. Expected listing price = issue price (upper band) + GMP. Expected return % = GMP ÷ issue price × 100. Profit per lot = GMP × lot size.
  3. Live page. This page re-reads the data file every 5 minutes and sorts each IPO into open, closed-awaiting-listing or upcoming by its dates.
  4. Accuracy check. After an IPO lists, its final GMP is saved next to the actual listing gain, so the “GMP vs actual” section below shows how reliable GMP has really been.

Important: GMP is an unofficial, unregulated grey-market estimate. It is not an official figure and can be wrong or manipulated. This project is for learning and information only, not investment advice.

Formula

Average GMP (₹) = (GMP₁ + GMP₂ + … + GMPₙ) ÷ n
n = number of sources quoting a GMP for that IPO (maximum 5)
Expected return (%) = Average GMP ÷ Issue price (upper band) × 100
Expected listing price (₹) = Issue price + Average GMP

Illustrative example: issue price ₹500; five sources quote ₹40, ₹44, ₹46, ₹50 and ₹45. Average GMP = 225 ÷ 5 = ₹45, so expected return = 45 ÷ 500 × 100 = 9.0% and expected listing price = ₹545.

Only sources that quote a premium for an IPO are counted. A ₹0 shown by IPOWatch or IPO Guru is treated as “no quote” unless another source quotes a premium. IPOs with no quote anywhere show “No GMP quoted yet”.
